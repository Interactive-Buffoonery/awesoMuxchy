# Visual parity achieved

This is the positive, evidence-backed register of components that have reached
the pinned macOS reference's visible and interaction quality. It is deliberately
empty until a component satisfies every gate in `VISUAL_PARITY_AUDIT.md`:
paired equivalent-state captures, complete meaningful-state interaction,
original-resolution inspection, keyboard and accessibility verification,
native Wayland release execution, passing preflight, and clean references and
pinned submodules.

Implementation progress and incomplete evidence belong in
`VISUAL_PARITY_AUDIT.md`, the implementation-status files, and the visual-QA
index—not here.
